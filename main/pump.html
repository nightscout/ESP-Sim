This is a pod.
A new board starts as an Omnipod 5. Switching forgets the current pod and starts a new, unpaired one of the other type: discard the current pod in the app first. Omnipod 5 pairs with apps whose OmnipodKit supports it, such as Loop 3.14.7 and Trio 1.0 or later.

Base model

The model is the base serial the app reads out of the advertisement. Switching it ends the activation, so the phone activates a fresh patch.

Base serial

Type this exact string in the app when it asks for the base serial: 4A12D828 is a 200U base (MD0201), 52DF1614 a 300U base (MD8301). The advertisement carries it reversed (28 D8 12 4A), which is the form the app matches on; the string above stays the one you type. A serial the app cannot derive a model from is refused here.

Change the cartridge

As on the pump: suspend it first, then put in a new cartridge (the pump rewinds), prime the tubing and fill the cannula. Each is logged in the pump's history with its amount, for the app to read. The primes come out of the cartridge. Resume the pump when you're done.
The encrypted firmware (V05, V35) talks only under a session key that the phone and pump agree in the pump's key exchange, and the pump runs that exchange only for a server key it trusts. This simulated pump trusts its own, made at random on this board (no real pump's key); the panel does not hand it out, so a phone cannot run the key exchange with it yet. The clear-text firmware (V65, V03, V02) needs none of this. The pump pairs over Bluetooth by passkey: type the number shown at the top of this card.
